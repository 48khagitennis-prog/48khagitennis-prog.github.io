プライバシーポリシー

柴田 圭（48K、以下「運営者」）は、48K Shorts 自動投稿（以下「本アプリ」）におけるデータの取り扱いを以下のとおり定めます。本アプリは運営者のYouTubeチャンネルを管理するための専用アプリであり、YouTube API Servicesを利用します。

1. 取得・保存する情報

Google認証情報OAuthのアクセストークン、リフレッシュトークンおよび認証に必要な設定。Googleアカウントのパスワードは取得・保存しません。
YouTubeの情報認証したチャンネルのID・表示名・ハンドル、投稿動画のID、処理状態、公開状態、公開予約日時など、投稿先確認と投稿管理に必要な情報。
動画・投稿データ運営者が指定した動画、ファイル名・保存場所・ファイルハッシュ、字幕と音声の解析結果、タイトル・説明文・タグの下書き、関連記事URL、投稿日時、エラー・再実行履歴。

2. 利用目的と権限

動画の解析、投稿文の作成、投稿先確認、YouTubeへのアップロード、公開予約・設定更新、処理結果の確認、重複防止および障害対応に利用します。OAuthスコープ「youtube.force-ssl」を使用します。Googleの同意画面が示す権限には広い操作範囲が含まれますが、本アプリの実装で使用するのはチャンネル確認と動画の投稿・状態確認・公開設定更新です。コメント投稿などの機能はありません。

3. 保存場所と外部への送信

認証トークン、動画、解析結果、投稿履歴は運営者のMacに保存します。承認された動画ファイルと投稿内容は、YouTube Data API経由でGoogle／YouTubeへ送信します。字幕・音声の解析はローカルで行い、Google認証データを外部の生成AIサービスへ送信しません。関連記事の選定にはnoteの公開記事情報を利用します。

この案内サイトには、動画アップロード、Googleログイン、独自のアクセス解析、広告、訪問者情報を入力するフォームを設けていません。配信基盤が運用・セキュリティ上のアクセス情報を処理する場合があります。外部リンクを開くと、リンク先サービスの規約・プライバシーポリシーが適用されます。

4. 共有と制限付き利用

Google APIから得たユーザーデータを販売したり、広告配信・広告プロファイリング・汎用AIモデルの学習に利用したりしません。Google／YouTubeへの必要な送信、運営者による管理、法令に基づく対応を除き、第三者へ提供しません。Google APIから受け取る情報の利用および他のアプリへの転送は、制限付き利用の要件を含むGoogle API Services User Data Policyに従います。

5. 保持期間・削除

認証トークンは、承認された投稿運用に必要な期間保存します。YouTube APIから取得した情報は、継続運用中に最新状態を再確認します。保存するAPIデータは適用されるYouTubeの保持期間に従い、30日以内の更新または削除を行う運用とします。運営者が作成した原本動画・投稿文・ファイルハッシュなどは、投稿管理に必要な期間保存します。

保存データの削除を希望する場合は、下記メールへご連絡ください。本人確認のうえ、対象となる認証情報・APIデータをできる限り速やかに、7日以内に削除します。削除時は自動運用を停止し、重複防止用の履歴を失うことによる再投稿リスクも確認します。ローカルデータの削除では、YouTube上の動画や予約は削除されません。YouTube上の削除・予約解除はYouTube Studioで行ってください。

6. 認証の取り消し

Googleアカウントの接続済みアプリ設定から「48K Shorts 自動投稿」のアクセスを取り消せます。取り消した場合は運営者へご連絡ください。自動処理を停止し、関連する認証情報・APIデータを7日以内に削除する対応を行います。Google側で取り消しても、YouTubeへ送信済みの公開予約は残るため、必要に応じてStudioで解除してください。

7. 安全管理とお問い合わせ

認証ファイルへのアクセスを制限し、公開ウェブサイトやソースの配布物へ認証トークンを含めません。Macおよびバックアップの保護は運営者が管理します。
