利用規約

1. 対象と目的

48K Shorts 自動投稿は、柴田 圭（48K）が自身のYouTubeチャンネルへの動画投稿を管理するために使用するアプリです。一般向けの登録サービスや有料投稿代行サービスではありません。

2. 同意と投稿の管理

本アプリを使用する運営者は、この利用規約とプライバシーポリシーを確認し、Google OAuthで必要な権限を承認します。初回の限定公開テストと本番運用の承認後に、指定したチャンネルへ自動投稿・公開予約を行います。生成された投稿文と関連記事は運営者が確認・修正でき、自動処理を停止できます。

3. YouTubeの規約

本アプリはYouTube API Servicesを使用します。本アプリの使用により、運営者はYouTube利用規約にも拘束されることに同意します。YouTubeのコミュニティガイドライン、著作権規則、API利用条件および適用法令を守って運用します。

4. コンテンツと生成文

投稿する動画・音声・字幕・画像について、必要な権利と許諾を運営者が確認します。字幕・音声の認識や関連付けには誤りが生じ得るため、投稿文の正確性、関連記事との関係、収録時点と現在の情報の違いを確認します。本アプリは再生数、収益、検索順位や審査通過を保証しません。

5. 動作と停止

予約の補充には、Macの起動・ログイン、ネットワーク接続、有効な認証と利用可能なAPI枠が必要です。Google／YouTube側の仕様、制限、認証失効などにより処理が止まる場合があります。YouTubeへ送信済みの予約は、本アプリを停止してもYouTube側に残ります。
